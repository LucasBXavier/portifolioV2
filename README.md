# 💼 Portfólio - Lucas Boareto Xavier

Bem-vindo ao meu portfólio profissional. Este é um projeto autoral desenvolvido para apresentar minha trajetória, projetos e stack como Desenvolvedor Full Stack com foco em Backend (Java, Spring Boot e Arquitetura de Software).

---

## 🎯 Sobre o Projeto

Este portfólio foi construído do zero para fugir da estética repetitiva de templates prontos. O design segue uma linha **dark premium**, minimalista e tecnológica, inspirada em produtos como Linear, Vercel e Stripe, com identidade visual própria (paleta escura + destaque em ciano, tipografia Krona One + SUSE).

O objetivo não é só listar projetos, mas transmitir atenção aos detalhes, boas práticas de engenharia e uma experiência de navegação fluida do primeiro segundo até o contato final.

### ✨ Destaques

- **Design autoral**: paleta, tipografia e composições visuais próprias, sem cara de template ou site gerado por IA
- **Animações fluidas**: scroll reveal, hover magnético, marquee infinito e microinterações com Framer Motion
- **Showcase de projetos criativo**: cada projeto tem uma representação visual sob medida — dashboard abstrato, simulação de chat do Telegram, preview de site — em vez de screenshots genéricos
- **Skills sem porcentagem**: hierarquia das tecnologias comunicada por tamanho e destaque dos chips, não por barrinhas arbitrárias
- **Totalmente responsivo**: layout e hierarquia visual adaptados de verdade para mobile, tablet e desktop (não apenas empilhado)
- **Performance e acessibilidade**: fontes otimizadas, `prefers-reduced-motion` respeitado, navegação por teclado

## 📄 Seções

✅ **Hero** — apresentação com composição visual (avatar, code card, badges flutuantes)

✅ **Skills** — arsenal técnico agrupado por categoria (Backend, Frontend, DevOps & Cloud, Banco de Dados, IA) + faixa de destaques
✅ **Projetos** — showcase alternado com Maintora, GastroInfo e Finance Bot
✅ **Serviços** — o que ofereço como desenvolvedor
✅ **Processo** — como conduzo um projeto do início à entrega
✅ **Contato** — email, WhatsApp e Instagram, com CTA direto

## 🛠️ Tecnologias Utilizadas

- **Next.js 16** (App Router) — framework React com renderização otimizada
- **TypeScript** — tipagem estática em todo o projeto
- **Framer Motion** — animações e microinterações
- **CSS Modules** — estilização isolada por componente
- **Lucide React** — ícones

## 🚀 Como Executar Localmente

```bash
git clone https://github.com/LucasBXavier/portifolioV2.git
cd portifolioV2
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) para ver o resultado.

Para gerar a build de produção:

```bash
npm run build
npm run start
```
